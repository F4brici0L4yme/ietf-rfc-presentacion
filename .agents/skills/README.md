# research-skills-pack

Four complementary skills that glue your existing research skills into a grounded pipeline.

- research-pipeline: orchestrator, stages, gates, handoff files
- evidence-ledger: structured cited claims + validator script
- research-gap-analysis: ledger -> gaps.md
- research-idea-ranking: candidates -> novelty-checked, ranked ideas.md

Install: extract into your skills folder next to the others.
Requires python3 (stdlib only) for scripts/check_ledger.py.
