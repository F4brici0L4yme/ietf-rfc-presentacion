# La IETF y los RFC — Informe y demos

Trabajo del curso **Redes y Comunicación de Datos** sobre la IETF y la serie RFC.

## Contenido

- `La_IETF_y_los_RFC.pdf` — informe en formato IEEE (3 páginas).
- `ietf-rfc.typ` — fuente Typst del informe.
- `demos/touying/ietf-touying.pdf` — demo de diapositivas con Touying.
- `demos/slidev/ietf-slidev.pdf` — demo de diapositivas con Slidev.
- `demos/brief.md` — guion visual compartido de las demos.
- `organizacion-tema.pdf` — rúbrica del trabajo.
- `conference-template-a4.docx` — plantilla IEEE de referencia.
- `diapos-template.pdf` — plantilla visual de diapositivas.
